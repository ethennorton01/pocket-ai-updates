# Pocket AI USB updates

Use the releases in this repository to download Pocket AI files for your USB. Each release lists what it includes and how to use the files.

## Update your USB

1. Open the [Pocket AI releases page](https://github.com/ethennorton01/pocket-ai-updates/releases).
2. Review the release notes and choose the file you need.
3. Download the file while online and save it to your Pocket AI USB.
4. Follow the instructions included with the release, then open Pocket AI from your USB.

## Offline maps

Download a .pmtiles map file and its matching SHA-256 checksum while online. Save the map file to your USB. In Pocket AI, select **Maps**, choose **Open a map file**, and select the saved file. Open one map at a time and check the intended area before relying on it offline. You may need to select the map again after reopening Pocket AI.

Map credits and coverage details are included with each release.
