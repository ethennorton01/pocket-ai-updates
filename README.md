# Pocket AI downloads

Download offline maps for all 50 states, Washington, D.C., and five U.S. territories from the [United States map collection](https://github.com/ethennorton01/pocket-ai-updates/releases/tag/offline-maps-2026-11-10-batch-1), or use the [state and territory selector on Pocket AI](https://pocketaiusa.com/maps/). Larger states are divided into overlapping regions.

Download the `.pmtiles` file while online, then open Pocket AI, select **Maps**, choose **Open a map file**, and select your download. Map credits, coverage details, and checksums are included with the release.

Pocket AI updates and release notes will also appear in [Releases](https://github.com/ethennorton01/pocket-ai-updates/releases).

For product information and support, visit [Pocket AI](https://pocketaiusa.com/).

Customer chats, personal files, licenses, and device data do not belong in this repository.
