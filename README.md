# Pocket AI downloads

Download offline maps for all 50 states, Washington, D.C., and five U.S. territories from the [United States map collection](https://github.com/ethennorton01/pocket-ai-updates/releases/tag/offline-maps-2026-11-10-batch-1), or use the [state and territory selector on Pocket AI](https://pocketaiusa.com/maps/). Larger states are divided into overlapping regions.

Download the `.pmtiles` file and its matching SHA-256 checksum while online. In Pocket AI, select **Maps**, choose **Open a map file**, and select the downloaded file. Map credits and coverage details are included with each release. A map download adds map data; it does not update Pocket AI app files.

## App update availability

Releases in this repository currently contain offline `.pmtiles` maps and SHA-256 checksums only. GitHub's autogenerated source archives are not app updates or installers. No versioned, compatible, signed Pocket AI app package or updater is published here. Do not run an installer from the current releases or expect a PASS result.

App installation instructions will appear here only when a compatible signed app package and verified updater are published. If a future v2 update is released, a genuine existing USB with only a cached v1 lease will need an internet connection once after upgrading to complete the online v2 bind and receive its lease before offline use. If binding fails, the existing credential and cached v1 state remain available for retry.

For product information and support, visit [Pocket AI](https://pocketaiusa.com/).

Customer chats, personal files, licenses, and device data do not belong in this repository.
